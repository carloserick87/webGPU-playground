# GPU Programming

![webGPU](img/webgpu-logo.svg)


## Goals

- Understand GPU vs CPU architecture.
- Learn WebGPU fundamentals.
- Work with GPUAdapter and GPUDevice.
- Create and manage GPUBuffer resources.
- Write compute shaders using WGSL.
- Build parallel computing experiments.
- Explore fluid simulations and ray tracing.

## Technologies

- TypeScript
- WebGPU
- WGSL
- Vite
- JavaScript
